## Builtins

**Core**:
- exit
- cd
- pwd

**Job control**:
- jobs
- fg
- bg

**Capabilities**
- Pipelines and andor sequences
- Redirections
- Variable expansion and assignment
- Basic file globbing

**Redirects**
- You can redirect stdout, stderr and stdin with >, 2> and < respectively
- The redirect for a command must come after the exectuable
- One of the fd's can have multiple redirect targets; the last one is used
